# Directories and awesome lists

Submit after the v1.0.0 release, one or two per day. Read each list's contribution rules first;
most want one line in alphabetical order and a PR title like "Add Velo PDF".

Suggested entry line:

```md
- [Velo PDF](https://github.com/adirel/velo-pdf) - Installable PWA PDF viewer for huge files (100,000+ pages): instant jump and zoom, full-text search, offline.
```

| Where | What to submit | Notes |
|---|---|---|
| `hemanth/awesome-pwa` | PR, "Apps" section | PWA-focused list |
| `sindresorhus/awesome` sub-lists for PDF (search GitHub for "awesome pdf") | PR | Look for a "Viewers" or "Tools" section |
| `sorrycc/awesome-javascript` | PR, under PDF or Other | Big list, strict format |
| `dzharii/awesome-typescript` | PR, "Apps" or "Products" | |

| store.app, appscope.net and other PWA galleries | Submission form | Use the social preview image |
